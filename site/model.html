Live accuracy (since go-live)

Every published forecast is checked against what Barmah actually did once that day's reading arrives. If live error runs above 1.5× the backtest error, retraining is triggered automatically (the new model still has to beat the champion to replace it). Timestral is checked the same way, for information only: it isn't trained here, so there is nothing to retrain.

Model history (MLflow registry)

Every trained version. A new version becomes champion only if it beats both the "no change" baseline and the current champion on the same test period. Ties don't count.

Limits

  • These explanations describe the model, not the river's physics. A large push from an input means the model leans on it, not that it causes the change.
  • Related inputs (for example, Yarrawonga's level on consecutive days) share credit; that's why inputs are shown in groups.
  • The backtest uses corrected historical readings. Live forecasts use provisional data, so real-world accuracy will be somewhat worse; forecast-vs-actual monitoring will measure it.
  • The river is regulated: an unannounced change in dam releases can't be predicted from past data.
